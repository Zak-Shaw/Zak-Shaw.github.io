# Code Review

## Overview

This code review examines the original version of the Weight-Tracking Application prior to enhancement. The purpose of the review was to analyze the existing structure, identify areas for improvement, and outline planned enhancements across software design, algorithms, and database implementation.

---

## Existing Functionality

The original application allowed users to:
- Create and authenticate user accounts
- Log weight entries with associated dates
- Set and retrieve goal weight values
- Store and retrieve data using SQLite

The application functioned correctly, but there were opportunities to improve structure, efficiency, and database organization.

---

## Enhancements Overview

The following enhancements were implemented to strengthen the application across the three required areas of Computer Science:

### Enhancement 1: Software Design and Engineering

The application was refactored to improve structure, organization, and maintainability. Code components were reorganized for clearer separation of responsibilities, and improvements were made to UI layout and overall flow. These changes focused on making the system easier to understand, modify, and expand.

### Enhancement 2: Algorithms and Data Structures

Enhancements were made to improve how data is processed and presented. Sorting functionality and progress calculations were implemented to improve efficiency and provide clearer feedback to users. These updates required evaluating trade-offs between simplicity and performance while maintaining readable code.

### Enhancement 3: Databases

The database schema was expanded to support additional functionality, including new tables and improved data relationships. CRUD operations were refined, and data handling was structured more intentionally to improve scalability and organization.
